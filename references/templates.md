### 模板 D2：版式与体例速查（Gate 3 每篇都要记，Gate 5 对标用）

```
□ 摘要体例：几段？三段式("针对X→本文提出Y→结果表明Z")？字数？
□ 引言体例：几段？是否编号("0 引言"/"引言")？末段是否点出本文工作？
□ 结论体例：标题叫"结论/结束语/结论与建议"？
           是否分条编号 (1)(2)(3)？几条？分条前有无引导句("主要结论如下")？
           每条是"主题句+展开"还是单句？末尾有无独立的总述/展望段？
□ 章节编号：一级标题形式（1 / 一 / 第1章）、二级标题形式
□ 表格线型：全框线 / 三线表 / 无竖线；表题在图上方还是下方
□ 图表题命名：是否"表1　XXX"格式、正文中如何引用图表
□ 引号与标点：中文弯引号 / 直角引号；顿号连接词用法；括号全半角
□ 著录细节：参考文献标点全半角、类型标识 [J]/[S]/[D]、页码前空格
□ 作者简介写法：要素顺序、职称写"名称"还是"等级"、是否必带邮箱
```
> 为什么单列这一维：这些"编辑一眼能抓"的格式特征，用六维表里的"结构"一行概括不住。
> 血案：2026-11-18 成稿后作者问"结论为什么分段、范文也这样吗"，主笔不得不回头重翻 PDF 才确认
> 六篇范文结论全为 (1)(2)(3)(4) 分条——说明拆解阶段就没把结论体例记下来。

## 模板 E：本刊写作偏好报告（Gate 3 汇总）

```

一、选题偏好：偏理论/案例/政策解读；高频主题；避开的主题
二、标题公式：（字数区间 + 句式 + 高频词 + 可套用结构）
三、结构骨架：（章节数、每章功能；摘要/引言/结论写法）
四、篇幅配比：（全文区间、各章占比）
五、文风：（人称、语气、段落、案例用法）
六、硬指标基线：（文献__条、图表__个、数据点__个、基金__）
七、版式与体例基线：（摘要/引言/结论体例、表格线型、引号形式、著录细节、作者简介写法——逐项注明"基于 N 篇范文"）
八、可复用的"隐形模板"：一段话总结，作为 Gate 5 写作准则
```
